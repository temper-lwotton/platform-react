# Get Video

Retrieve a single video with full details.

## Endpoint

```
GET /api/videos/{idOrSlug}
```

## Description

Returns complete video details including playback information, transcript, and user interaction state.

## Authentication

Optional for public videos. Required for members-only or space videos.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `idOrSlug` | string | Yes | Video ID or slug |

### Error Responses

#### Video Not Found (404)

```json
{
  "success": false,
  "error": {
    "code": "VIDEO_NOT_FOUND",
    "message": "Video 'invalid-slug' does not exist"
  }
}
```

## Example Request

```bash
curl -X GET "https://api.example.com/api/videos/introduction-to-python" \
  -H "Authorization: Bearer <token>"
```

## Notes

- View count incremented on access
- User interaction included for authenticated users
- Quality options for uploaded videos
- Related content based on categories/tags
