# CMS Settings Endpoints

API endpoints for managing CMS settings.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| [GET](./get-all.md) | `/api/cms/settings` | Get all settings |
| [GET](./get-category.md) | `/api/cms/settings/{category}` | Get category |
| [PATCH](./update-general.md) | `/api/cms/settings/general` | Update general |
| [PATCH](./update-media.md) | `/api/cms/settings/media` | Update media |
| [PATCH](./update-reading.md) | `/api/cms/settings/reading` | Update reading |
| [PATCH](./update-writing.md) | `/api/cms/settings/writing` | Update writing |
| [PATCH](./update-discussion.md) | `/api/cms/settings/discussion` | Update discussion |
| [PATCH](./update-permalinks.md) | `/api/cms/settings/permalinks` | Update permalinks |
| [PATCH](./update-theme.md) | `/api/cms/settings/theme` | Update theme |
| [POST](./reset.md) | `/api/cms/settings/reset` | Reset to defaults |
