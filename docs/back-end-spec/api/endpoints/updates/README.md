# Updates Endpoints

API endpoints for managing status updates.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| [GET](./list.md) | `/api/updates` | List updates (feed) |
| [GET](./get.md) | `/api/updates/{id}` | Get single update |
| [POST](./create.md) | `/api/updates` | Create update |
| [DELETE](./delete.md) | `/api/updates/{id}` | Delete update |
