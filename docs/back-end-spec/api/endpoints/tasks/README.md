# Tasks Endpoints

API endpoints for managing user tasks.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| [GET](./list.md) | `/api/tasks` | List user's tasks |
| [GET](./stats.md) | `/api/tasks/stats` | Get task statistics |
| [POST](./complete.md) | `/api/tasks/{id}/complete` | Mark as completed |
| [PATCH](./update-status.md) | `/api/tasks/{id}/status` | Update status |
