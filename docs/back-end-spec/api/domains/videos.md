# **API Domain Specification: Videos**

*(Authoritative, conceptual, human-readable)*

## **API Domain: `Videos`**

### **Description**

The Videos domain manages video-only content for learning and knowledge sharing. It provides:

* Dedicated video content with optimized playback
* Support for uploads and external embeds (YouTube, Vimeo)
* Transcripts and closed captions
* Space-scoped or platform-wide content
* Watch progress tracking
* Commenting and engagement features
* Video collections and series

Videos serve as the primary multimedia learning format, enabling creators to share video tutorials, presentations, and educational content with community members.

---

## **Domain Responsibility**

### **This domain is responsible for:**

* Creating and managing video content
* Video metadata and categorization
* Transcript and caption management
* Watch progress tracking
* Engagement features (likes, bookmarks)
* Comment threads on videos
* Content visibility and access control
* Video collections and playlists

### **Out of scope:**

* Written articles (see [Articles](./articles.md))
* Downloadable files (see [Downloads](./downloads.md))
* Video transcoding (infrastructure concern)
* Video hosting/CDN (infrastructure concern)
* Live streaming (future enhancement)

## **Owned Data Models**

### **Core Entities**

#### **Video**

Complete video content with metadata.

```typescript
interface Video {
  id: string;
  slug: string;
  status: ContentStatus;

  // Space association
  spaceId?: string;                    // Null for platform-wide
  space?: SpaceReference;

  // Core content
  title: string;
  description: string;                 // Rich text
  excerpt?: string;                    // Short summary
  thumbnail?: VideoThumbnail;

  // Video source
  source: VideoSource;

  // Transcript and captions
  transcript?: string;                 // Full transcript text
  captions?: VideoCaption[];

  // Metadata
  author: ContentAuthor;
  publishedAt?: string;                // ISO 8601
  updatedAt: string;                   // ISO 8601
  createdAt: string;                   // ISO 8601

  // Categorization
  categories: Category[];
  tags: Tag[];
  difficulty?: DifficultyLevel;

  // Engagement
  duration: number;                    // Seconds
  viewCount: number;
  likeCount: number;
  bookmarkCount: number;
  commentCount: number;

  // Access control
  visibility: ContentVisibility;
  restrictedToSpaces?: string[];

  // Collections
  collectionId?: string;
  collectionOrder?: number;

  // Related content
  relatedVideos?: string[];
  relatedArticles?: string[];
  relatedDownloads?: string[];
}

interface SpaceReference {
  id: string;
  title: string;
  slug: string;
  icon?: string;
}
```

#### **VideoSource**

Video source information.

```typescript
interface VideoSource {
  type: VideoSourceType;
  url: string;                         // Source URL
  embedUrl?: string;                   // Embed iframe URL
  videoId?: string;                    // External video ID
  duration: number;                    // Seconds
  quality?: VideoQuality[];
}

interface VideoQuality {
  label: string;                       // e.g., "1080p", "720p"
  url: string;
  width: number;
  height: number;
  bitrate?: number;
}

type VideoSourceType = 'upload' | 'youtube' | 'vimeo' | 'wistia' | 'embed';
```

#### **VideoThumbnail**

Thumbnail images for video.

```typescript
interface VideoThumbnail {
  id: string;
  url: string;
  alt?: string;
  width: number;
  height: number;
  thumbnails: {
    small: string;                     // 320px
    medium: string;                    // 640px
    large: string;                     // 1280px
  };
  generatedAt?: string;                // Auto-generated timestamp
}
```

#### **VideoCaption**

Closed caption track.

```typescript
interface VideoCaption {
  id: string;
  language: string;                    // ISO 639-1 code
  label: string;                       // Display name
  url: string;                         // VTT file URL
  isDefault: boolean;
  isAutoGenerated: boolean;
}
```

#### **VideoCollection**

Playlist or series of videos.

```typescript
interface VideoCollection {
  id: string;
  slug: string;
  title: string;
  description?: string;
  thumbnail?: VideoThumbnail;
  videoCount: number;
  totalDuration: number;               // Seconds
  author: ContentAuthor;
  visibility: ContentVisibility;
  spaceId?: string;
  createdAt: string;
  updatedAt: string;
}
```

#### **UserInteraction**

User's interaction state with a video.

```typescript
interface VideoUserInteraction {
  hasLiked: boolean;
  hasBookmarked: boolean;
  watchProgress: number;               // Percentage (0-100)
  watchedSeconds: number;              // Seconds watched
  lastWatchedAt?: string;              // ISO 8601

```

## **Relationships & Concepts**

### **Video Lifecycle**

```
Upload/Embed Video
    ↓
Add Metadata (title, description, categories)
    ↓
Add Transcript/Captions (optional)
    ↓
Publish → Available for Viewing
    ↓
Track Watch Progress
    ↓
Archive (when outdated)
```

### **Space Association**

Videos can be:
- **Platform-wide** (`spaceId: null`) - Available based on visibility settings
- **Space-specific** (`spaceId: "space_123"`) - Available to space members

### **Video Sources**

| Source | Use Case | Features |
|--------|----------|----------|
| `upload` | Self-hosted | Full control, quality options |
| `youtube` | External hosting | Wide compatibility, auto-captions |
| `vimeo` | External hosting | Professional features |
| `wistia` | Marketing videos | Analytics, CTAs |
| `embed` | Other platforms | Generic iframe |

### **Watch Progress**

- Progress tracked as percentage (0-100) and seconds watched
- Saved periodically as user watches
- Enables "continue watching" functionality
- Completion tracked when 90%+ watched

### **Video Collections**

- Group related videos into playlists/series
- Ordered for sequential viewing
- Track collection-level progress
- Common for courses or tutorials

### **Commenting**

Videos support threaded comments (same as articles/discussions):
- Top-level comments
- Reply threads
- Timestamp references
- Author responses highlighted

---

## **Business Rules**

1. **Title Required**: Title is mandatory (max 200 characters)
2. **Video Required**: Must have a valid video source
3. **Slug Unique**: Slugs must be unique across platform
4. **Duration Required**: Duration must be set (auto-detected for uploads)
5. **Completion Threshold**: Video considered complete at 90% watched
6. **Space Visibility**: Space videos inherit visibility from space settings
7. **Caption Format**: Captions must be VTT format
8. **Thumbnail Generation**: Auto-generated for uploads if not provided
9. **External Validation**: External video URLs validated on creation

### **Authentication**

* **Required:** Yes for write operations; varies for read
* **Token:** JWT Bearer token in Authorization header

| Action | Who Can Perform |
|--------|-----------------|

| List space videos | Space members |
| View public video | Anyone |
| View members video | Authenticated users |
| View space video | Space members |
| Create platform video | Administrators, content creators |
| Create space video | Space administrators, content creators |
| Edit own video | Video author |
| Edit any video | Administrators |
| Publish video | Editors, administrators |
| Delete video | Administrators |
| Like/bookmark | Authenticated users |
| Comment | Authenticated users (if enabled) |
| Manage collections | Content creators, administrators |

## **API Capabilities Overview**

The Videos API allows consumers to:

* **List videos** with filtering by space, category, author
* **Get video** full details for playback
* **Create video** with upload or embed
* **Update video** metadata and source
* **Publish video** from draft status
* **Archive video** to hide from listings
* **Like/bookmark video** for engagement
* **Track watch progress** for resume functionality
* **List/add comments** on videos
* **Manage collections** (create, update, reorder)

## **Domain Events & Side Effects**

### **Events Emitted**

| Event | Trigger | Payload |
|-------|---------|---------|
| `video.created` | New video created | `{ videoId, authorId, spaceId }` |
| `video.published` | Video published | `{ videoId, authorId }` |
| `video.updated` | Video updated | `{ videoId, updatedBy }` |
| `video.archived` | Video archived | `{ videoId }` |
| `video.liked` | User liked video | `{ videoId, userId }` |
| `video.commented` | New comment added | `{ videoId, commentId, userId }` |
| `video.watched` | User completed video | `{ videoId, userId }` |
| `video.milestone` | View milestone reached | `{ videoId, milestone, count }` |

### **Side Effects**

| Event | Side Effect |
|-------|-------------|
| `video.published` | Index for search |
| `video.published` | Notify space members (if space video) |
| `video.liked` | Increment like count |
| `video.commented` | Increment comment count |
| `video.commented` | Notify video author |
| `video.watched` | Update completion stats |
| Video viewed | Increment view count |
| Video played | Update watch progress |

## **Performance & Constraints**

### **Request Volume**

| Endpoint | Expected Volume |
|----------|-----------------|
| List videos | High (homepage, listings) |
| Get video | High (playback) |
| Update progress | Very High (during playback) |
| Like/bookmark | Medium |
| Comments | Medium |

### **Pagination**

* Video list: Cursor-based
* Comments: Offset-based
* Default limit: 20 videos, 50 comments

### **Rate Limiting**

| Endpoint | Limit |
|----------|-------|
| Create video | 10/hour |
| Update progress | 60/minute |
| Like/bookmark | 100/minute |
| Add comment | 30/minute |

### **Known Trade-offs**

* External video metadata fetched on creation
* Progress saves are debounced on client
* View counts may have slight delay
