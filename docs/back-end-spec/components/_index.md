## Documentation Template

Each component document includes:
- **Description**: Purpose and usage context
- **Location**: File path in the codebase
- **Props Interface**: Input parameters with types
- **Internal State**: useState variables
- **Dependencies**: Child components and libraries
- **Data Requirements**: Expected data types and sources
- **Events & Callbacks**: Event handlers
- **Styling**: CSS modules and customization
- **Usage Example**: Code snippets
- **Related Components**: Parent/sibling/child relationships
